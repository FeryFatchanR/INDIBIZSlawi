# Panduan Admin (non-teknis)

## Mengubah halaman dengan Visual Builder
1. **Website → Pages** → klik **Builder** pada halaman.
2. **Kiri – Komponen**: klik komponen untuk menambah setelah section terpilih, atau seret ke **Struktur halaman**/canvas.
3. **Struktur halaman**: seret ⋮⋮ untuk mengurutkan, atau tombol ↑ ↓. Ikon ⧉ duplikat, ◉ sembunyikan, ✕ hapus.
   Keyboard: fokus baris lalu **Alt+↑/↓**.
4. **Tengah – Canvas**: klik section untuk memilih. Judul tertentu bisa diedit langsung dengan klik pada teks.
   Tombol **Desktop/Tablet/Mobile** menampilkan tampilan asli tiap perangkat.
5. **Kanan – Properti**: tab *Konten*, *Desain*, *Responsif* (atur kolom/visibilitas per perangkat), *Visibilitas*.
   Perubahan diterapkan otomatis (atau klik **Terapkan**).
6. Semua perubahan tersimpan sebagai **draft** — pengunjung belum melihatnya. Klik **Preview** untuk melihat versi draft.
7. Klik **Publish** untuk menayangkan. **Simpan Draft** membuat titik revisi bernama.
8. Salah publish? **Pengaturan halaman → Riwayat Revisi → Pulihkan ke draft → Publish**.

> Jika muncul pesan *"Halaman telah diubah oleh pengguna lain"*, klik **Muat versi terbaru** agar tidak menimpa pekerjaan rekan.

## Gambar
Unggah di **Media → Media Library** (JPG/PNG/WebP/GIF ≤5 MB, MP4/WebM ≤50 MB, PDF ≤10 MB). Isi *Alt text* untuk SEO.
Media yang sedang dipakai tidak bisa dihapus. **Ganti file** memperbarui semua halaman yang memakainya.

## Produk
**Produk → Products**: isi tab Informasi, Detail Layanan, Media, SEO & Publikasi. Spesifikasi, galeri, dan FAQ produk
dikelola di bagian bawah halaman edit. Status *Published* = tampil di `/layanan`.

## Leads
**Leads → Leads**: tab New / In progress / Won / Lost. Buka lead → **Ubah status**, **Assign sales**,
**Tambah catatan** (bisa menjadwalkan follow-up). Sales hanya melihat lead yang di-assign kepadanya.
**Export Excel/CSV** tersedia untuk Administrator; file dikirim lewat notifikasi (ikon lonceng).

## Role
| Role | Dapat |
|---|---|
| Super Admin | semua, termasuk user, role, website settings, custom script |
| Administrator | halaman & builder, publish, produk, media, marketing, semua leads, export |
| Marketing | konten marketing (kampanye, banner, testimoni, dll.), media, leads yang di-assign |
| Sales | leads yang di-assign: lihat, ubah status, catatan |
